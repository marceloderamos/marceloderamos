## About me

I'm Marcelo, a software developer focused on practical applications and interactive learning. I build tools around real problems: understanding SQL through experimentation, practising programming skills, organising learning materials and supporting creative work.

My projects span Python desktop applications, Flask web apps and JavaScript automation.

## Selected work

### ModuleForge
**Modular application tooling · In development**

A project for building reusable, modular applications, with a working foundation and application-generation tooling planned.

### SQL Quest
**Interactive SQL learning · Desktop application**

A visual learning application combining explanations, hands-on SQLite experiments, debugging exercises and saved progress. Includes a workspace for writing SQL and inspecting query results and database structure.

### Typing Tutor for Programmers
**Programming practice · Desktop application**

A typing tutor with everyday and programmer practice modes, US/UK keyboard layouts, finger guidance, custom lessons and progress tracking.

### NameForge
**Word exploration · Local application**

A word-list and name-creation tool for collecting vocabulary, transforming and combining words, saving reusable lists and exporting results to CSV.

### Marcelo's Learning Studio
**Learning tools · In development**

A Windows learning environment for organising video lessons, notes, playlists and progress, with specialised learning studios and coding-workspace development.
